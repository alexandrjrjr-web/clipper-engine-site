Política de privacidade

O Clipper Engine é executado localmente no computador do usuário. Não vendemos dados, não exibimos publicidade e não usamos rastreamento de terceiros.

Dados e contas

Quando o usuário conecta uma rede social, o aplicativo usa somente as permissões OAuth concedidas para a finalidade escolhida, como publicar vídeos. Tokens ficam armazenados localmente, com acesso restrito ao usuário do computador.

Vídeos

Os arquivos de vídeo permanecem no armazenamento indicado pelo usuário. O Clipper não envia arquivos para serviços externos sem uma ação de publicação autorizada.

Contato

Solicitações relacionadas à privacidade devem ser encaminhadas ao responsável pelo projeto Clipper Engine.
